Overview

Trash Through the Dimensions is a narrative adventure created for the Ubisoft 2024 Game Jam. It combines inter-dimensional exploration, dialogue-driven storytelling, top-down gameplay, and a distinctive “trash-zapping” combat hook into a compact but feature-rich prototype.

What makes it stand out as a portfolio piece is the speed of its delivery: the project had to balance high-quality character presentation with a very compressed implementation window for the rest of the game.

My Role: Solo Developer

I built the project solo for the Ubisoft 2024 Game Jam over 14 days. A major part of that schedule went into the Live2D pipeline, which meant the rest of the game's systems, level content, and integration work had to be delivered under extreme time pressure.

  • Gameplay Programming & Systems Design (C#)
  • UI/UX Design & Implementation
  • Spine2D animated characters
  • Live2D animated characters
  • Story and dialogue implementation
  • Sound design & integration
  • Game and level design
  • Project management & version control (Git)

Key Systems

Core Progression Systems

To support a story-driven adventure across multiple scenes, the project needed a quest system tied to save/load state. That foundation lets the player move through narrative content without the game feeling like a sequence of isolated jam scenes.

Character Asset Pipeline

I created the Live2D and Spine2D playable characters that define much of the project's identity. In a jam context, that asset pipeline was both a creative opportunity and a scheduling challenge, because visual quality had to coexist with fast gameplay implementation.

Design Decisions

This project is a good example of prioritization under constraint. High-quality character art was a key part of the vision, which meant dedicating the first nine days to illustrating and rigging four full-body Live2D characters.

That left only the final five days for core gameplay systems, story implementation, level work, audio integration, and the Spine2D playable character setup. The result is less about raw feature count and more about the ability to make fast, targeted decisions under jam pressure.
