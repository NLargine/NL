Fruit Merge

Casual physics puzzle game built for clean browser play

View Project

Overview

Fruit Merge is a casual physics-based puzzle game where players drop fruit into a container, merge matching pieces into larger ones, and manage risk as the pile grows toward a lose state.

The project was built as a small but complete solo game with a focus on readable mechanics, satisfying feedback, and WebGL-friendly browser performance.

Play on itch.io

My Role

I developed Fruit Merge solo from prototype to release, using it as a focused exercise in gameplay readability, physics tuning, and browser deployment.

  • Solo development from prototype to release
  • Gameplay and physics programming (Unity / C#)
  • Merge systems and scoring logic
  • UI, audio feedback, and polish
  • WebGL optimization and deployment

Key Features

  • Physics-based merge mechanics with combo scoring
  • Clear danger feedback tied to lose conditions
  • Object pooling for browser performance
  • Fully playable in-browser
