Overview

Idle Combat Demo is a browser-based incremental RPG built from scratch in vanilla JavaScript. The project focuses on scalable combat rules, structured progression, modular UI rendering, and maintainable state management without relying on frameworks.

Play Live Demo

My Role: Solo Developer

This project was built as a systems-focused game that demonstrates how combat, progression, UI structure, and data organization can stay manageable in a browser environment without framework abstractions.

  • Game systems architecture for combat, scaling, and progression
  • Mission and multi-wave encounter design
  • Itemization and rarity framework
  • Skill unlock and stat modifier design
  • Modular UI rendering and separation of logic from presentation
  • State management and data structuring
  • Frontend UI/UX design in vanilla JavaScript and CSS
  • Deployment via GitHub Pages

Core Systems & Architecture

Combat Engine

Modular combat logic with crit chance, evasion, status effects, and dynamically scaling enemies tied to player progression.

Mission Framework

Multi-wave missions with area modifiers that change combat rules and create variation between runs.

Item & Rarity System

Items use rarity-based multipliers and calculated values rather than hardcoded one-off stat tables.

Scaling & Progression

XP curves, unlockable skills, and progression tiers built to support incremental RPG pacing.

Modular UI Rendering

UI rendering is separated from the core game rules through dedicated update and display functions, making the code easier to extend.

Vanilla Implementation

The project was intentionally built without frameworks to showcase direct JavaScript, DOM, and state-management fundamentals.
